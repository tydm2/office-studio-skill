# 风格选择器与换轮协议（style-switcher）

> 供 orchestrator 在澄清阶段与交付迭代阶段使用，目标：**让用户快速选到满意的风格；不满意时一轮一轮换，直到满意为止**。
> 风格规格本体在 `style-catalog.md`；本文件只写「怎么选」与「怎么换」。

## 一、风格选择器（澄清阶段用）

**原则**：14 个风格一次全列出来会眼花，先问「方向」，再给 3-4 个具体选项。

### 第 1 步：按场景问方向（ask_user_question，单选）
根据文档类型/受众/用途，把风格按「性格」分四类引导用户：

| 方向 | 风格选项（style_id） | 一句话视觉特征 |
|------|----------------------|----------------|
| 稳重专业 | `business-professional` / `mckinsey` / `official` | 深蓝白底、结论先行、规范严谨 |
| 现代高级 | `minimal` / `swiss-grid` / `glassmorphism` / `dark-tech` | 留白/网格/玻璃/深色，克制有设计感 |
| 个性鲜明 | `brutalist` / `retro-y2k` / `creative` / `aurora-gradient` | 撞色/复古/活力/渐变，记忆点强 |
| 亲和内容 | `flat-illustration` / `editorial-magazine` / `academic` | 插画/杂志/学术，易读有温度 |

### 第 2 步：给具体选项
- 用户选中方向 → 列出该方向下 3-4 个 `style_id`，每个附**一句话视觉特征 + 参考来源**（如「瑞士网格风：网格对齐+超大标题+单强调色，参考 GitHub hugohe3/ppt-master 的设计规格」），让用户选或说「你来定」。
- 用户说「你来定/推荐一个」 → orchestrator 按受众与用途推荐，并说明理由。
- 用户直接指定风格名/贴图/链接 → 映射到最近 `style_id`，找不到就按该参考新建风格条目（追加进 style-catalog「最近更新」区）。

### 第 3 步：锁定并派发
- 将选定的 `style_id` 写入 `plan-NN.md` 元信息。
- 配图需求（封面/插画/图标）同步把 `style_id` 传给 `office-imagegen`（按其中的 style_id→绘图风格映射生图），保证**图文风格统一**。

## 二、换一轮协议（交付不满意时用）

**触发**：用户对已交付文档说「风格不满意 / 换一种风格 / 换个风格重做 / 这风格不好看换一个」等，或主动要求换风格。

**标准流程（一轮）**：

1. **确认换的是风格不是内容**：先问清「内容/结构保留，只换视觉风格？」默认**内容与叙事结构全部保留**，只换 `style_id`；用户若也要改内容，则按内容修改处理。
2. **重新展示选项**：按「一、风格选择器」重新给选项；可以结合用户上一轮反馈缩小范围（如「上次商务感太重，这次换成有个性的方向」→ 推 `brutalist` / `retro-y2k` / `aurora-gradient`）。
3. **出新 plan**：新建 `plan-NN.md`（NN 递增）或对原 plan 出修订版（`plan-NN-rev2.md`），头部 `style_id` 换成新值，其余元信息（title/doc_type/audience/purpose/length/data_source）**沿用上一版已确认值**，并在正文注明「换轮：仅风格由 X 换为 Y」。
4. **重新派发**：用 `subagent` 派给对应专家（PPT→slide-designer / Word→word-crafter / Excel→sheet-analyst），提示词明确：内容按上一版 plan 沿用、**只重做视觉风格**、产出新文件（NN 递增，**不覆盖上一版文件**）。
5. **交付对比**：交付新文件时附「本轮改动说明」写进 `-meta.md`，并给用户**两版风格对比一句话**（旧 X vs 新 Y 各有什么气质），方便用户决定留下哪版。
6. **换轮次数建议**：建议最多连续 3 轮风格尝试；3 轮后仍未满意 → 引导用户：a) 提供参考图/链接精确定位风格；b) 锁定风格后在**细节层面**微调（配色微调/字体/版式局部），不再整轮换。

**示例话术**（orchestrator 对用户）：
> 「收到，我们换一轮风格重做：内容结构全部保留，只换视觉。这次往『个性鲜明』方向推荐 3 个：粗野主义（撞色+粗描边）、复古千禧（奶油底+渐变）、极光渐变（青紫光晕+情绪留白），参考社区设计趋势。选一个？或者你有参考图/链接也行。」

## 三、与配图的联动

- 换风格时，文档内**配图同步换**：`office-imagegen` 按新 `style_id` 的绘图风格映射重新生成封面/插画/图标，嵌入新文件；旧的配图不搬入新文件（除非用户要求保留某张）。
- 图生图场景：可把上一版封面图作为输入，提示词写「改成{新风格}，构图不变」（按 office-imagegen 的图生图用法），快速得到新风格封面。
