# 全流水线通用质量红线（quality-redlines）

大脑与各专家共同遵守的全局红线；各专家另有专属质检清单。

## 数据与事实
- [ ] 所有数字、单位、百分比、图表与正文**一致**，无矛盾
- [ ] 不虚构数据、不杜撰行业基准；缺数据时标注"待补充"，不瞎编
- [ ] 数据注明来源（能追溯），口径统一

## 内容与表达
- [ ] 结论先行：每份文档开篇/每页/每表先给结论，再给支撑
- [ ] 不用 AI 味套话（"众所周知/综上所述/在当今…"）；不用"很多/少量/大幅"等模糊量词
- [ ] 逻辑自洽：论点-论据-论证闭环，无跳跃

## 格式与可打开
- [ ] 产出文件用 python-docx / python-pptx / openpyxl 生成，交付前校验可正常打开
- [ ] 版式符合所选 `style_id` 的配色/字体/版式规格
- [ ] 命名规范：`outputs/<type>/<NN>.<ext>` 递增编号，无覆盖
- [ ] 品牌套件（v2）：plan 含 `brand_kit` 时，产出必须应用品牌资产（品牌色/字体/页眉页脚/Logo），品牌优先于风格库；同一 brand_id 多件套主色/字体/页眉页脚逐项一致

## 合规
- [ ] 不泄露用户隐私/密钥；不把数据发往外部
- [ ] 引用第三方内容注明来源，无版权风险
