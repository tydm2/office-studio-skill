# 澄清清单与派发判据（task-intake）

大脑接单时按此清单澄清，任何一项缺失都要问，不许替用户脑补。

## 澄清清单（选项式提问）
| 维度 | 必问项 | 选项示例 |
|------|--------|----------|
| 文档类型 | doc_type | word / ppt / excel |
| 主题用途 | title + purpose | 汇报/提案/总结/论文/报表/宣传 |
| 目标受众 | audience | 领导/客户/评委/同事/公众/学术 |
| 篇幅 | length | 字数/页数/数据行数/章节数 |
| 风格 | style_id | 见 shared/style-catalog.md 六个风格 |
| 源数据 | data_source | 是否有 Excel/现有文档/品牌色 |

## 派发判据（一句话职责映射）
- doc_type=word → 派 `word-crafter`（吃 plan+风格 → 吐 .docx）
- doc_type=ppt → 派 `slide-designer`（吃 plan+风格 → 吐 .pptx）
- doc_type=excel → 派 `sheet-analyst`（吃数据+plan+风格 → 吐 .xlsx）

## 派发提示词自包含检查（派发前必过）
通读派发提示词，凡出现"这个/同上/按之前说的"等指代，问一句"子代理没有主会话，它知道指什么吗？"不知道就补全注入。

## 风格选择提示
向用户呈现风格时，用一句话讲清每种风格的"感觉"（如"商务专业=深蓝+结论先行，适合汇报"），并给出推荐（按用途默认推荐一个），降低用户选择成本。

## 编辑模式澄清清单（用户提供现有文档时）
- 修改目标（改什么）：具体到段落/页面/单元格，越具体越好
- 保留项（哪些不动）：原格式、已有结论、原始数据
- 风格：默认沿用原风格；切换需用户明确指定 style_id
- 影响范围：仅此文件，还是同步更新相关产出（如报表联动 PPT）

## 识别现有文件（编辑模式必做）
用 python-docx / python-pptx / openpyxl 提取：段落与标题层级（word）、幻灯片数与页面元素（ppt）、工作表名与表头/行数（excel），汇总为内容概要注入派发提示词。识别不出结构时，请用户提供文字版。
