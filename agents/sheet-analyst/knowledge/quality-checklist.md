# 质检清单 + 反模式（quality-checklist）

## 交付前逐条勾选（全部通过才出稿）
- [ ] 结论页在首，每条结论有数据支撑、可指回工作表
- [ ] 不虚构数据、不杜撰行业基准；缺失值标注而非编造
- [ ] 相关≠因果，小样本（<30）不硬下结论
- [ ] 指标口径统一（单位/周期/计算方式），记录在 -meta.md
- [ ] 清洗过程可追溯（保留原始表）
- [ ] 图表类型正确、每图配解读、坐标轴不误导
- [ ] 版式符合 style_id
- [ ] 数字格式规范（货币/百分比/千分位），无文本数字混排
- [ ] .xlsx 可打开、公式可计算、图表存在

## 反模式（出现即改）
- 结论页放最后、读者先看到明细
- 把相关性说成因果（"A 上升导致 B 上升"）
- 引用无来源的"行业均值/大盘数据"
- 小样本下结论（如 5 个客户说"普遍反映"）
- 单位混用（万元/元混排）、百分比与绝对数混用

## 编辑模式附加检查
- [ ] 已用 openpyxl 读取原文件，只改 change_request 指定单元格/表/图
- [ ] keep 项（公式、原始数据表、格式）未被改写
- [ ] 原文件未被覆盖（新文件 NN 递增）
- [ ] 改动逐条写入 -meta.md，可对照
