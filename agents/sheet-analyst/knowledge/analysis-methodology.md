# 数据分析六段式流程（analysis-methodology）

## 一、流程总览（严格按序执行）
```
1. 需求与口径确认 → 2. 数据清洗 → 3. 指标计算 → 4. 可视化 → 5. 结论提炼 → 6. 版式与交付
```

### 1. 需求与口径确认
- 先确认：分析目标、受众（领导看结论/运营看明细）、时间周期、单位口径。
- 口径（如"营收=不含税到账"）记录进 `-meta.md`，全文统一。

### 2. 数据清洗
- 去重、缺失值处理（标注而非删除重要行）、异常值判定（3σ 或业务规则，注明依据）。
- 类型规范化：数字列转数值、日期统一格式、文本去首尾空格。
- 清洗过程可追溯：保留原始工作表不动，另建"清洗后"表。

### 3. 指标计算
- 常用指标：总量、同比/环比、占比、增长率、客单价、渗透率、留存率等，公式写清。
- 同比/环比口径：同比=与上年同期比，环比=与上一期比，不得混用。
- 关键计算在"计算指标"表留公式与说明单元格。

### 4. 可视化
- 趋势→折线、占比→饼/环形、对比→柱状、分布→直方图/散点。
- 每张图配一句解读（这图说明什么结论），解读写入图表附近或结论页。
- 坐标轴不截断误导、色盲友好配色。

### 5. 结论提炼（结论先行）
- 结论页放**最前**（工作簿第一张可见），每条结论：结论句 + 支撑数据 + 指向工作表。
- 区分事实与推断：推断必须标注依据，缺依据标"待验证"。
- **不杜撰行业基准**：无来源的行业均值不得引用；**相关≠因果**；**小样本（<30）不下结论**。

### 6. 版式与交付
- 按 style_id 落地配色/字体/数字格式；交付前逐条过质检清单。

## 二、统计规范速查
- 样本量 <30：报告描述性统计，不做显著性结论。
- 相关性：报告 r 值与样本量，不表述为因果。
- 缺失率 >20% 的字段：结论中降权并注明。
