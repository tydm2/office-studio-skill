# 质检清单 + 反模式（quality-checklist）

## 交付前逐条勾选（全部通过才出稿）
- [ ] 每页有且只有一个 action title（结论式标题）
- [ ] 单页正文 ≤ 40 字，至多一个图表
- [ ] 无整段文字搬页、无 bullet 堆砌
- [ ] 叙事结构完整（封面→正文→结论→致谢）
- [ ] 图表选择正确（趋势=折线、占比=饼、对比=柱）
- [ ] 图表配解读句，数据与标题结论一致，不虚构
- [ ] 配色/字体/对齐符合 style_id
- [ ] 页数符合要求（偏差 ≤15%）
- [ ] .pptx 正常打开，无溢出/重叠/字体缺失

## 反模式（出现即改）
- 标题用"XX介绍/XX分析"等话题式标题
- 整页贴大段文字（PPT 不是文档）
- 无结论的图表堆砌
- 默认模板丑配色、未按风格库
- 数据与标题结论矛盾

## 编辑模式附加检查
- [ ] 已用 python-pptx 读取原文件，只改指定页面/元素
- [ ] 未改动页与母版样式保持原样
- [ ] 原文件未被覆盖（新文件 NN 递增）
- [ ] 改动逐条写入 -meta.md，可对照
