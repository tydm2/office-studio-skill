# PPT 叙事结构与信息密度规范（narrative-methodology）

## 一、叙事弧（按用途选）
| 用途 | 结构 | 页面节奏 |
|------|------|----------|
| 汇报/总结 | 结论→结果→过程→下一步 | 首页先抛结论，再倒叙展开 |
| 路演/提案 | 痛点→方案→优势→证据→行动 | 前 3 页抓住注意力，方案是主体 |
| 学术汇报 | 背景→方法→结果→讨论→结论 | 方法可复现、结果图表化 |
| 宣传/营销 | 钩子→价值→信任→行动 | 视觉冲击 + 一句话卖点 |

## 二、每页一论点（action title）
- 标题必须是**结论**，不是话题名：❌"市场分析" ✅"华东市场是下一季度唯一增长引擎"。
- 每页只证明一个 message：标题=结论，正文/图=支撑。
- 一页读下来，不看正文只看标题也能懂全片逻辑。

## 三、信息密度规范（硬约束）
- 单页正文 ≤ 40 字；用短句 + 关键词，绝不整段搬文字。
- 每页至多一个图表/图示；图表必须配一句解读（结论）。
- 标题/正文/数据三级字号梯度：标题 28-32pt、正文 18-20pt、图表注释 12-14pt。

## 四、图表选择
| 数据关系 | 图表 |
|----------|------|
| 趋势 | 折线图 |
| 占比 | 饼图/环形 |
| 对比 | 柱状图 |
| 分布 | 直方图/散点 |
| 流程/结构 | 流程图/SmartArt |

## 五、负面约束
- 不用默认丑模板、不堆砌 bullet、不贴大段文字。
- 不虚构数据、不截断坐标轴误导。
- 不用与风格冲突的配色；对齐严格（左对齐/网格对齐）。
