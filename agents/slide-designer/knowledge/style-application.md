# 十四风格在 PPT 的落地规格（style-application）

> 完整风格定义（配色/字体/版式/语气/适用/三端要点/参考来源）见 `../../shared/style-catalog.md`；本文件只写 **PPT 端落地要点**。换风格时配图同步按 `office-imagegen` 的 style_id→绘图风格映射重生成，保证图文统一。

## 经典六风格（1-6）

## business-professional（商务专业）
- 深蓝 `#1F3864` 标题栏 + 白底正文，强调色天蓝 `#2E74B5`
- 标题微软雅黑加粗 28pt，正文 18pt
- 版式：16:9，标题栏+内容区，图表带数据标签与来源

## mckinsey（麦肯锡）
- 白底，主色深青/墨黑，强调色亮蓝 `#0072CE`
- 超大标题（32pt+）+ 极小正文，标题即结论
- 每页一个 message，单一图表，脚注少量

## academic（学术）
- 白底黑字，少量深红/藏蓝强调，图表色盲友好配色
- 标题宋体加粗 28pt，正文宋体 18pt，图表带编号（图1/表1）
- 公式清晰、引用标注

## minimal（极简）
- 白底+近黑 `#1A1A1A`，单一强调色，大量留白
- 每页至多一句话 + 一张图，大字号（标题 36pt+）
- 无多余装饰

## creative（活力创意）
- 高饱和渐变（橙→紫/青→粉），图标+色块+大字
- 标题圆体/粗体，正文无衬线
- 不对称构图，每页视觉冲击

## official（政务）
- 庄重配色（红头 `#C00000` 仅用于标题栏/文号），正文黑
- 标题小标宋 28pt，正文仿宋 18pt
- 政务图表规范，单位/口径注明

## 社区借鉴八风格（7-14，2026-08-24 入库）

## swiss-grid（瑞士网格风）
- 白底 + 近黑字 `#0A0A0A` + 单一强调色（瑞士红 `#E30613`/蓝 `#0057B7`）
- 超大标题 40pt+ 与极小标注 9pt 反差；Helvetica/Arial/思源黑体
- 版式：严格网格对齐（4/6/12 栏）、元素编号、斜线/色块仅作点缀
- python-pptx 落地：用文本框精确对齐网格（等距留白），强调色只用于页码/编号/下划线

## glassmorphism（玻璃拟态风）
- 彩色渐变底（紫蓝/青粉）+ 半透明玻璃卡片 `rgba(255,255,255,0.15)` + 白字
- 细体无衬线（Inter Light/思源黑体 Light）
- python-pptx 落地：渐变背景用 `fill.gradient()`；玻璃卡片用「形状填充透明度 10-20% + 柔化边缘 + 细白描边」模拟，文字白字加轻微阴影保证可读

## editorial-magazine（杂志编辑风）
- 米白纸底 `#F7F4EF` + 墨黑字 + 1-2 种杂志色（酒红/橄榄绿/钴蓝）
- 衬线大标题（思源宋体）+ 无衬线正文，字号对比强烈
- 版式：大图出血页、超大引言页（引语 40pt+）、页码/章节号贯穿
- python-pptx 落地：封面用全出血图片（图占满全页）、引言页居中大字、每页右上角章节号

## dark-tech（暗色科技风）
- 深底 `#0B1220` + 主色青蓝 `#38BDF8` + 点缀亮紫/荧光绿
- 几何无衬线（Rajdhani/思源黑体），数字用等宽 JetBrains Mono
- 版式：深色背景 + 卡片分区 + 发光边框（亮色细线描边模拟）、关键数字放大
- python-pptx 落地：深色矩形铺底、卡片用亮色 1pt 描边、数据用等宽字体放大至 40pt+

## aurora-gradient（极光渐变风）
- 极光渐变（青 `#00F5A0`→蓝 `#00D9F5`→紫 `#7C3AED`）+ 白/浅灰字
- 细体无衬线大字
- 版式：满屏渐变 + 低饱和文字区、光晕感、每页一个情绪焦点
- python-pptx 落地：渐变背景 `fill.gradient()`（多停靠点）；文字区垫半透明白/黑矩形保证对比度；渐变别满屏高饱和

## flat-illustration（扁平插画风）
- 米白底 + 双主色（低饱和）+ 少量强调色
- 圆润无衬线（圆体/思源黑体）
- 版式：插画大图 + 圆角卡片 + 一句话论点
- 配图：直接调用 office-imagegen 按「扁平插画」映射生成（可参考 Storyset/unDraw 构图语言）；圆角卡片用 `round_rectangle`

## brutalist（粗野主义/孟菲斯）
- 纯白/纯黑底 + 高饱和撞色（荧光黄 `#F5FF00`/粉 `#FF4D6D`/青 `#00C2FF`）+ 粗黑描边
- 超粗无衬线（粗黑体）
- 版式：不对称构图、大字块、几何拼贴、刻意打破网格
- python-pptx 落地：撞色矩形色块 + 粗描边文本框；**可读性优先，撞色只用于装饰不用于正文**

## retro-y2k（复古千禧风）
- 奶油底/粉紫渐变 + 铬银高光 + 天蓝/亮粉点缀
- 圆体标题、可点缀像素/对话框元素
- 版式：渐变 + 贴纸感元素 + 对话框气泡 + 怀旧网格
- python-pptx 落地：圆形/圆角贴纸色块、对话框形状（用 `MSO_SHAPE.ROUNDED_RECTANGLE` + 小三角组合）、装饰适度不遮挡信息
