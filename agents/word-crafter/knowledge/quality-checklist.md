# 质检清单 + 禁词表（quality-checklist）

## 交付前逐条勾选（全部通过才出稿）
- [ ] 结论先行：开篇有结论，每节首句是论点
- [ ] 结构清晰：金字塔/MECE，无逻辑跳跃
- [ ] 无 AI 腔套话（见下方禁词表）
- [ ] 无模糊量词（很多/大量/大幅/显著），除非有数据
- [ ] 数字、单位、图表、正文一致，无虚构
- [ ] 标题层级正确、编号连续
- [ ] 学术/公文场景符合规范（编号、参考文献、公文格式）
- [ ] 篇幅符合要求（偏差 ≤10%）
- [ ] .docx 可正常打开，样式已应用

## 禁词表（出现即改）
AI 腔套话：众所周知、综上所述、总而言之、值得一提的是、在当今社会、赋能、抓手、闭环、颗粒度、落地、抓手、打通、对齐、拉通、沉淀、心智、抓手
模糊量词：很多、大量、少量、大幅、显著、巨大、极佳、非常好、十分

## 常见反模式
- 段落堆砌排比、空洞抒情
- 标题用"关于…的思考/浅析"等虚题
- 图表无解读句、数据无来源
- 结论埋在文末，读者读不到重点

## 编辑模式附加检查
- [ ] 已用 python-docx 读取原文件，改动只落在 change_request 范围
- [ ] keep 项（原格式/已有结论/数据）未被改写
- [ ] 原文件未被覆盖（新文件 NN 递增）
- [ ] 改动逐条写入 -meta.md，可对照
